# Docs archive

Superseded or overflow material only. **Do not** treat archive files as current — check [LIVE.md](../LIVE.md) and [SCOPE.md](../SCOPE.md) first.

## When to archive

| Trigger | Action |
|---------|--------|
| [LIVE.md](../LIVE.md) > ~500 lines | Move superseded sections to `LIVE_<n>.md`; link from top of LIVE |
| Personal journal > ~25 entries | Move oldest to `journal_<username>_<n>.md`; link both ways |

## Naming

- `LIVE_1.md`, `LIVE_2.md`, …
- `journal_<git-username>_<n>.md`

Never delete archived content — link and trim active files only.
