# Toastmasters Daily - Design Theme

## Typography

### Font Family
- **Primary Font**: `'Inter'` (Variable font, weights 100-900)
- **Fallback Fonts**: `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`

### Font Sizes
- **Heading 1**: `28px`
- **Subtitle**: `16px`
- **Body Text**: `16px`
- **Notification Message**: `14px`
- **Button Text**: `16px`

### Font Weights
- **Regular**: `400`
- **Medium**: `500`
- **Semi-bold**: `600`

### Letter Spacing
- **Code Input**: `8px`
- **Default**: `normal`

## Color Palette

### Primary Colors
- **Primary Dark**: `#424242` (Buttons, primary actions)
- **Primary Dark Hover**: `#616161` (Button hover state)

### Background Colors
- **Page Background**: `#f5f5f5` (Main page background)
- **Input Background**: `#F2F1F0` (Code input field)
- **White**: `#ffffff` / `white` (Cards, notifications)
- **Hover Background**: `#f5f5f5` (Interactive element hover)

### Text Colors
- **Primary Text**: `#212121` (Main text content)
- **Primary Text (RGBA)**: `rgba(0, 0, 0, 0.87)` (Headings)
- **Secondary Text**: `#757575` (Subtitles, secondary text)
- **Placeholder Text**: `#9e9e9e` (Input placeholders)
- **White Text**: `white` (Text on dark backgrounds)

### Notification Colors
- **Error**: `#d32f2f` (Error notifications, error states)
- **Success**: `#2e7d32` (Success notifications, success states)
- **Info**: `#1976d2` (Info notifications, informational states)

### Shadow & Border Colors
- **Shadow**: `rgba(0, 0, 0, 0.15)` (Default shadows)
- **Border**: `rgba(0, 0, 0, 0.08)` (Subtle borders)

## Spacing

### Padding
- **Page Padding**: `20px`
- **Notification Padding**: `16px 20px`
- **Input Padding**: `16px 20px`
- **Button Padding**: `10px 24px` (Login button), `16px` (Join button height: 48px)

### Gaps
- **Notification Gap**: `12px` (Space between notification elements)

### Border Radius
- **Small**: `4px` (Close button)
- **Medium**: `8px` (Buttons, notifications)
- **Large**: `12px` (Input fields)

## Shadows

### Box Shadows
- **Notification Shadow**: `0 4px 12px rgba(0, 0, 0, 0.15)`
- **Button Hover Shadow**: `0 4px 12px rgba(0, 0, 0, 0.15)`

## Animations

### Durations
- **Fast**: `0.2s` (Hover transitions)
- **Medium**: `0.3s` (Slide animations)
- **Slow**: `0.8s` (Spinner rotation)

### Easing
- **Default**: `ease-out`
- **Linear**: `linear` (Spinner)

## Z-Index

- **Notification**: `1000` (Above all content)
- **Top Banner**: `100` (Fixed header)

## Responsive Breakpoints

- **Mobile**: `max-width: 600px`

- **Width**: `140px` (Join button)
- **Height**: `48px` (Join button)
- **Border Radius**: `8px`
- **Font Weight**: `500`

### Input Fields
- **Width**: `280px` (Code input container)
- **Border Radius**: `12px`
- **Letter Spacing**: `8px` (Code input)

### Notifications
- **Min Width**: `280px`
- **Max Width**: `400px`
- **Border Left Width**: `3px`
